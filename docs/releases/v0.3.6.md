# Hestia v0.3.6

更新应用图标为「薄荷播放环」，统一 Windows 程序、窗口、托盘、网页标志和浏览器图标。采用浅绿、浅蓝为主、浅黄和杏橙点缀的配色。

## 更新

- 提供 16–256 px 的七档 Windows 图标资源，保留透明边角。
- 网页图标地址增加版本参数，刷新后使用新图标。
- 增加图标母版、设计提示词和 Windows 资源导出脚本。
- 修复 Windows 构建脚本的换行与编码兼容性，并显式使用已包含的 vendor 依赖。
- 包含 v0.3.5 后合入的转码锁修复：等待首个转码分片时释放会话锁，避免阻塞其他转码操作。

## 下载与升级

- `Hestia.exe`：Windows x64 单文件程序。
- `Hestia-v0.3.6-windows-amd64.zip`：同一程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述两个文件的 SHA-256 校验值。

升级时先从托盘退出旧程序，再替换原目录中的 `Hestia.exe`。保留现有 `config.json` 和 `data` 文件夹。
