# Hestia v0.4.2

- 桌面端左侧主演列表新增即时搜索，可按姓名片段筛选主演。
- 媒体库根目录被删除、磁盘断开或路径无法访问时，重新扫描会隐藏该库已失效的内容，同时保留媒体库配置和观看进度。
- 控制台会提示检查路径或磁盘；路径恢复后可重新扫描，也可以手动移除媒体库。
- 媒体库内的文件夹被删除后，重新扫描会移除对应索引，其他文件夹不受影响。

应用不会周期性扫描；目录变化后请在控制台点击「重新扫描」，或重启程序。

## 下载

- `Hestia.exe`：Windows x64 单文件程序，支持应用内更新。
- `Hestia-v0.4.2-windows-amd64.zip`：相同程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。
