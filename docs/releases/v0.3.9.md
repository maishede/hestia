# Hestia v0.3.9

版本检查改为完全由用户触发。Windows 控制台打开时不再自动访问 GitHub，也不做定时检查；点击「检查更新」后才查询最新正式版。发现新版本时显示推荐安装提示和「下载并安装（将重启）」按钮。

下载安装流程保留 SHA-256 校验、旧 exe 备份和失败回滚；`config.json` 与 `data/` 保持不变。

## 下载

- `Hestia.exe`：Windows x64 单文件程序。
- `Hestia-v0.3.9-windows-amd64.zip`：相同程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。
