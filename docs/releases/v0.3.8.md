# Hestia v0.3.8

Windows 控制台支持在应用内检查、下载、校验和安装 GitHub Release 更新。更新完成后会保留 `config.json` 与 `data/`，并自动重启。

当 GitHub 匿名 REST API 达到共享访问限额时，版本检查会改用 GitHub 的最新 Release 页面跳转。下载仍使用 Release 中的 `Hestia.exe` 和 `SHA256SUMS.txt` 做 SHA-256 校验。

v0.3.6 及更早版本需要最后一次手动替换；后续版本可在控制台内一键更新。更新要求程序所在目录可写。

## 下载

- `Hestia.exe`：Windows x64 单文件程序。
- `Hestia-v0.3.8-windows-amd64.zip`：相同程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。
