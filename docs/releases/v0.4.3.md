# Hestia v0.4.3

- 重设计 Windows 控制台。媒体库成为主工作区，底栏集中显示服务状态、访问地址和打开网页入口。端口、开机自启、FFmpeg 和软件更新收进设置。
- 支持一键复制访问地址。文件夹列表清楚显示路径、媒体数、子文件夹数和扫描状态。
- 启动时先显示 Hestia 标志内的流光动画，控制台绘制后自动收起。WebView2 初始化失败或页面加载超时会显示提示，并记录到日志。
- 简化窗口关闭提示，可选择缩到托盘继续运行或退出服务。

## 下载

- `Hestia.exe`：Windows x64 单文件程序，支持应用内更新。
- `Hestia-v0.4.3-windows-amd64.zip`：相同程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。
