# Hestia v0.4.5

- Windows 控制台新增手动生成封面。任务可收起并继续运行，完成后会弹出结果。已有有效缓存的封面直接复用，未生成的项目可以展开查看文件名和原因。
- Windows 控制台和网页支持简体中文、English、日本語，分别记住所选语言。README 提供对应的三种语言。
- 搜索结果复用媒体列表的封面逻辑。搜索框可一键清除并回到全部合集。搜索时保留主演筛选栏，并按全部关键词命中结果统计主演数量。

## 下载

- `Hestia.exe` · Windows x64 单文件程序，支持应用内更新。
- `Hestia-v0.4.5-windows-amd64.zip` · 同一个程序的 ZIP 压缩包。
- `SHA256SUMS.txt` · 上述文件的 SHA-256 校验值。
