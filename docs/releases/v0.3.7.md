# Hestia v0.3.7

Windows 控制台现在会自动检查 GitHub 上的最新正式版。发现新版本后，点击「下载并安装（将重启）」即可下载 `Hestia.exe`、验证 SHA-256、备份当前 exe、替换并重新启动。配置文件和 `data` 目录不会被替换。

窗口启动时检查一次，之后每 6 小时检查一次；也可以手动点击「检查更新」。下载或替换失败会保留旧版本，并在窗口中显示错误。更新要求程序所在目录可写，且 Release 提供 `Hestia.exe` 与 SHA-256 校验信息。

v0.3.6 及更早版本尚未包含更新器，因此需要最后一次手动下载并替换本版本；从 v0.3.7 开始即可在窗口内更新后续版本。

## 下载

- `Hestia.exe`：Windows x64 单文件程序。
- `Hestia-v0.3.7-windows-amd64.zip`：相同程序的 ZIP 压缩包。
- `SHA256SUMS.txt`：上述文件的 SHA-256 校验值。
