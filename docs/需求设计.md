## 1. 背景与目标

### 1.1 痛点

1. 硬盘空间有限，影视资源分散在**多块磁盘、多个文件夹**中，查找和管理的成本高。
2. 观看设备已以**手机**为主，但资源都在 PC 上，手机直接访问不方便。
3. 希望有轻量的自用方案，而不是重量级的 Jellyfin/Emby/Plex。

### 1.2 产品目标

一套「**单文件服务启动器（exe）+ Web 播放器**」组合：

- PC 上双击运行一个 exe，配置多个媒体路径和端口，即启动 Web 服务；
- 手机 / PC 浏览器通过局域网访问，按文件名浏览、模糊搜索、点播；
- 用户端**完全不可见物理路径**，只看到文件夹名和文件名；
- 播放器针对触屏优化：倍速、亮度、音量手势、长按 2 倍速。

### 1.3 非目标（明确不做）

- 不支持公网 / 远程访问（Q4 已确认：仅局域网使用，不提供任何穿透方案）；
- 不做用户体系 / 密码认证（Q2 已确认：局域网自用，全程免登录）；
- 不做在线元数据刮削（封面直接用文件夹内已有图片，不联网刮削）；
- 不做上传 / 删除 / 改名（**只读**服务，保证源安全）。

> 备注：现成方案 Jellyfin/Emby 功能更全，但安装重、配置杂。本项目定位是"零安装、双击即用、手机优先"的极简自用工具。

## 2. 术语与目录层级约定

| 术语 | 定义 |
|---|---|
| 媒体库（Library） | 用户在启动器中配置的一个根路径（如 `D:\电影`），可配置多个 |
| 母文件夹 | 媒体库根下的第一层文件夹（浏览的起点） |
| 子文件夹 | 母文件夹下的文件夹（可再嵌套，但展示层级为两层为主） |
| 媒体项 | 视频文件或图片文件 |

目录层级约定：

```
媒体库根路径（配置项，如 D:\电影）
└── 母文件夹（如 "漫威系列"）
    └── 子文件夹（如 "钢铁侠 2008"）
        ├── 视频（mkv / mp4 / ...）
        └── 图片（poster.jpg / 截图 / ...，优先作为该文件夹封面）
```

- 浏览首页从**母文件夹**列表开始；
- 子文件夹内若还有更深层文件夹，允许继续向下浏览（不限死两层），但封面/统计主要针对两层结构。

## 3. 用户与核心场景

| # | 场景 | 描述 |
|---|---|---|
| S1 | 首次配置 | 双击 exe → 浏览器自动打开管理页 → 添加 `D:\电影`、`E:\剧集`、`F:\动漫` → 设置端口 8080 → 点"启动" → 页面显示局域网地址和二维码 |
| S2 | 手机观看 | 手机扫码（或输入 IP:8080）→ 看到母文件夹封面墙 → 点入子文件夹 → 点视频 → 全屏播放 → 手势调节 |
| S3 | 模糊搜索 | 顶栏输入"流浪"或"lddq"→ 全库文件名模糊匹配 → 点击结果直达播放 |
| S4 | 热配置 | 新买了磁盘 `G:\新资源` → 管理页添加 → **不重启服务**，增量扫描生效 |
| S5 | 中断续看 | 昨晚看到 42:15，今天打开自动从断点附近继续 |

## 4. 总体架构

```
┌─────────────────────────── PC（Win11 / macOS / Linux）───────────────────────────┐
│                                                                                  │
│  Hestia.exe（单文件，双击运行）                                                   │
│  ┌──────────────────────────────────────────────────────────────────────────┐    │
│  │ ① 服务宿主：进程生命周期 / 控制台 / 系统托盘(M2) / 防火墙引导               │    │
│  │ ② 配置模块：config.yaml 读写 + 热重载（路径增删即时生效）                   │    │
│  │ ③ 扫描索引器：全量/增量扫描媒体库 → SQLite 索引（文件名/层级/封面/时长）     │    │
│  │ ④ Web 服务：REST API + 内嵌前端静态资源 + 视频流（HTTP Range/206）          │    │
│  │ ⑤ 转码代理：外挂 ffmpeg 按需转 HLS（HEVC/MKV 兜底，MVP 内置）                │    │
│  └──────────────────────────────────────────────────────────────────────────┘    │
│                              ▲ HTTP（局域网）                                     │
└──────────────────────────────┼───────────────────────────────────────────────────┘
                    ┌─────────┴─────────┬──────────────────┬──────────────┐
                    │ 手机浏览器(主场景) │ 平板浏览器        │ PC 浏览器     │
                    │ iOS Safari/Chrome │                   │ Chrome/Edge… │
                    └───────────────────┴──────────────────┴──────────────┘
```

**关键决策：管理端与用户端同进程、同端口**，管理页挂在 `/admin` 路由下（免登录），避免再做桌面 GUI，天然跨平台。MVP 阶段启动器就是"控制台窗口 + 自动打开管理页"。

## 5. 功能需求（FR）

### 5.1 FR-1 服务启动器（PC 端）

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-1.1 | 单文件可执行程序，双击运行，无需安装、无需目标机装运行时 | P0 |
| FR-1.2 | 媒体路径配置：添加 / 编辑 / 删除 / 暂时停用多个媒体库根路径 | P0 |
| FR-1.3 | **热配置**：媒体路径增删改后即时生效（增量扫描新增项、下线移除项），无需重启进程；端口变更自动平滑重启监听 | P0 |
| FR-1.4 | 端口配置：默认 8080，可修改；管理页实时显示局域网访问地址（IP:端口）与**二维码**（手机扫码直达） | P0 |
| FR-1.5 | Web 服务启动 / 停止控制；启动后自动打开本机管理页 | P0 |
| FR-1.6 | 管理界面：`/admin` Web 页面，承载全部配置能力；配置同时持久化到 exe 同目录 `config.yaml`（支持手改后热加载） | P0 |
| FR-1.7 | 扫描：启动时全量扫描；运行期周期增量扫描（对比 mtime）；管理页可手动触发重扫并显示进度 | P0 |
| FR-1.8 | 转码引擎管理：运行时探测 ffmpeg（exe 同目录 → 系统 PATH），缺失时管理页提供一键下载指引；转码进程生命周期管理（起播创建、停止/超时自动销毁） | P0 |
| FR-1.9 | 系统托盘常驻（最小化到托盘、开机自启可选） | P2 |
| FR-1.10 | 运行日志：控制台输出 + 滚动文件，便于排障 | P1 |

### 5.2 FR-2 媒体库浏览（Web 用户端）

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-2.1 | 层级浏览：母文件夹列表 → 子文件夹 → 视频/图片 媒体项，支持继续向下进入更深层文件夹 | P0 |
| FR-2.2 | **路径不可见**：所有 API 与页面仅暴露内部 ID 与显示名，物理路径不出现任何返回体/URL 中 | P0 |
| FR-2.3 | 封面自动识别：文件夹封面 = 该文件夹内（含直接子层）图片，命名优先级 `poster.* > cover.* > folder.* > fanart.* > 其余第一张图`；无图时用默认占位图（M3 支持 ffmpeg 抽视频首帧做封面） | P0 |
| FR-2.4 | **分页：每页 20 项**；移动端无限滚动，桌面端无限滚动 + 回到顶部 | P0 |
| FR-2.5 | **列表排序**：支持按 **名称（自然排序，数值感知 + 中文本地化）、修改日期、大小** 三种字段排序，均可**正序/倒序**；排序选择器即时生效并记忆用户选择（localStorage），默认"名称正序"；同一页面中文件夹区与媒体区分别套用当前排序 | P0 |
| FR-2.6 | 图片媒体项可点击查看大图，左右滑动切换（轻量相册） | P1 |
| FR-2.7 | 首页"继续观看"：最近播放记录 + 断点进度条 | P1 |
| FR-2.8 | 视频/文件夹卡片显示：文件名（去扩展名）、大小、时长（有索引时）、新入库角标 | P1 |

### 5.3 FR-3 搜索

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-3.1 | 顶栏全局搜索框，对全库**文件名**（不含扩展名）+ 文件夹名模糊搜索 | P0 |
| FR-3.2 | 匹配规则：大小写不敏感；空格分词多关键词 AND；英文支持子序列模糊（`avgr` 匹配 `Avengers`）；中文子串匹配 | P0 |
| FR-3.3 | 输入防抖 300ms 即时出结果；结果分页 20，展示所属文件夹面包屑（仅文件夹名） | P0 |
| FR-3.4 | 拼音全拼/首字母搜索（如 `liulang` / `lldq` 匹配"流浪地球"） | P2 |

### 5.4 FR-4 播放器

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-4.1 | **默认最高清晰度**：直链播放源文件原画质（即文件自带最高）；服务端支持 HTTP Range（206），进度条任意拖动秒响应 | P0 |
| FR-4.2 | **倍速：0.5x / 1x / 1.5x / 2x / 2.5x / 3x / 4x / 5x** 八档菜单（1–5x 整数档 + 中间档，Q1 已确认），保持音调不变（`preservesPitch`） | P0 |
| FR-4.3 | **手势**（触屏为主，鼠标拖拽等效支持）：左半屏上下滑调**亮度**、右半屏上下滑调**音量**、**长按 2 倍速**（详见 5.4.1 手势规范） | P0 |
| FR-4.4 | 断点续播：localStorage 记录播放位置（±5s 精度），再次打开提示"从 xx:xx 继续" | P1 |
| FR-4.5 | 格式兼容（Q7 已确认 MVP 必须）：直链优先（MP4/MKV/WebM 中浏览器可解码的，如 H.264/AAC）；探测到无法解码时自动降级为**服务端 ffmpeg 转码 HLS**（h264/aac，veryfast），并对该文件记忆降级决策（转码引擎见 FR-1.8） | P0 |
| FR-4.6 | 控制栏：播放/暂停、进度条（可预览时间）、时长、倍速、全屏、音量（桌面端）；移动端控制栏 3 秒无操作自动隐藏 | P0 |
| FR-4.7 | 同文件夹内"上一个/下一个"视频切换 | P2 |
| FR-4.8 | **外挂字幕**（Q5 已确认）：与视频同名的 `.srt` / `.ass` 自动加载并默认开启；srt 转 vtt 走原生轨道，ass 由前端字幕引擎渲染 | P1 |
| FR-4.9 | 双击手势：屏幕左 1/3 双击后退 10s，右 1/3 双击快进 10s，中间双击播放/暂停（B 站式） | P2 |
| FR-4.10 | 画中画（桌面/安卓 Chrome） | P3 |
| FR-4.11 | 内嵌字幕：片源自带字幕轨经 ffmpeg 提取为可选轨道（多轨列出可选；ASS 特效轨在转码时烧入画面） | P2 |

#### 5.4.1 手势交互规范（触屏）

| 手势 | 动作 | 参数 |
|---|---|---|
| 左半屏 **垂直滑动** | 调节播放器画面亮度 | CSS `filter: brightness()`，范围 20%–100%，滑动满屏行程 ≈ 全量程；HUD 显示百分比；亮度记忆在 localStorage |
| 右半屏 **垂直滑动** | 调节播放音量 | `video.volume` 0–100%；HUD 显示百分比；⚠ iOS Safari 不允许 JS 设音量，见 8.2 的降级策略 |
| **长按** | 临时 2 倍速 | 按住 ≥ 500ms 触发（期间位移 < 10px 才算长按），松开恢复原速；触发时 HUD 显示"2x 快进中"并轻微放大画面 |
| 单击 | 显示 / 隐藏控制栏 | 300ms 内无第二次点击（与双击区分） |
| 水平滑动 | 进度 seek | 位移 > 24px 进入 seek 模式，HUD 显示目标时间（P2） |

工程约束：手势热区避开屏幕边缘 24px（防系统边缘返回）；`touch-action: none` + 屏蔽长按系统菜单（`-webkit-touch-callout: none; user-select: none` + `contextmenu` preventDefault）。

### 5.5 FR-5 安全

| 编号 | 需求 | 优先级 |
|---|---|---|
| FR-5.1 | 只读服务：无任何写操作 API | P0 |
| FR-5.2 | 防目录遍历：ID → 物理路径仅服务端内存/索引映射，流媒体端点只允许已索引文件；任何带路径参数的请求直接拒绝 | P0 |

| FR-5.4 | 封面/图片接口提供缩放参数（`?w=400`），避免手机端加载原图浪费流量 | P1 |

> 已确认（Q2）：局域网自用，**不做任何密码/认证**，管理页与用户端均免登录；如未来有需要再行扩展。

| 类别 | 指标 |

## 7. 技术选型建议（供实施评估，非需求约束）

**推荐方案 A：Go + 内嵌前端**

- 后端：Go（标准库 `net/http` 足够），单文件交叉编译 Win/macOS/Linux，零依赖部署；
- 索引：SQLite（`modernc.org/sqlite`，纯 Go 免 CGO，交叉编译无痛）；万级规模也可用内存索引 + JSON 持久化；
- 前端：Vite + Vue3（或 React）打包后 `go:embed` 进二进制；播放器可基于原生 `<video>` 自研手势层（手势逻辑简单，自研可控性最高）；
- 转码：运行时探测 ffmpeg（同目录 → PATH → 提示下载），按需 `ffmpeg -c:v libx264 -preset veryfast -c:a aac -f hls` 起进程，停止播放即销毁。

**备选方案 B：Tauri 2（Rust）**——原生托盘/GUI 体验最好，体积小，但构建链重、跨三平台打包成本高。若 M4 想要精致桌面端可迁移。

**备选方案 C：Electron / Node（pkg）**——体积 100MB+、内存占用高，不推荐。

## 8. 关键技术风险与对策

| # | 风险 | 对策 |
|---|---|---|
| 8.1 | **编码兼容**：手机浏览器对 HEVC(H.265)、AC3/DTS 音频、MKV 容器支持参差（Firefox 不播 MKV；安卓 Chrome HEVC 看机型；iOS Safari HEVC 硬解可播） | 播放前用已索引的编码信息 + 播放 `error` 事件双重判断 → 自动切服务端转码 HLS；对"已确认需转码"的文件记忆，下次直达 |
| 8.2 | **iOS Safari 禁止 JS 设置音量**（`video.volume` 只读） | 检测 iOS：右侧手势自动改为"进度 seek"，音量交给物理音量键；UI 首次弹出一次性提示说明 |
| 8.3 | 长按触发系统文本选择菜单 /呼出苹果边缘返回 | 见 5.4.1 工程约束（preventDefault + 边缘热区避让） |
| 8.4 | 3x–5x 高倍速下音画同步/音频 mute | `preservesPitch=true`；浏览器上限（Chrome 16x / Safari 8x）覆盖 5x；高倍速时保持出声但做回归测试 |
| 8.5 | 大目录扫描 IO 抖动、Windows 中文长路径 | 增量 mtime 对比 + 后台低优先级协程；全链路 UTF-8 + Windows `\\?\` 长路径前缀 |
| 8.6 | 端口被占 / 首次运行防火墙拦截 | 启动检测端口占用自动 +1 重试并提示；Win 首次运行给防火墙放行引导截图 |
| 8.7 | 视频直链 MIME/Range 处理错误导致无法拖动进度 | `.mkv` 返回 `video/x-matroska` 等；实现标准 Range/206；自动化测试覆盖 0-byte 起点与末尾 Range |

## 9. 数据模型（索引）

```sql
Library(   id, label, root_path, enabled, added_at )
Folder(    id, library_id, parent_id, name, depth,
           cover_media_id NULL, mtime )          -- id = hash(root_path + relative_path)
MediaItem( id, folder_id, kind video|image, name, ext,
           size, mtime, duration NULL, width NULL, height NULL,
           vcodec NULL, acodec NULL )            -- id 同上，配置不变则稳定
Progress(  media_id, position_ms, updated_at, device_key )   -- V2 多设备同步
```

> ID 采用 `sha1(rootPath + 相对路径)` 截断 16 字符的 Base62：配置不变时稳定（收藏/进度不因重启丢失），且天然不泄露路径。

## 10. API 草案（v1）

```
管理端（/admin 页面调用，免登录）
GET    /api/admin/libraries            列出媒体库（含扫描状态）
POST   /api/admin/libraries            { path, label }  新增 → 触发增量扫描（热）
PATCH  /api/admin/libraries/{id}       改 label / enabled
DELETE /api/admin/libraries/{id}       移除（只删索引不删文件）
POST   /api/admin/rescan               手动全量重扫
GET    /api/admin/config               端口 / 监听地址 / ffmpeg 等
PATCH  /api/admin/config               端口变更 → 平滑重启监听
GET    /api/admin/qrcode               局域网访问二维码 PNG

用户端（免认证，局域网自用）
GET    /api/folders?page=1&size=20&sort=name|mtime|size&order=asc|desc   根层 = 母文件夹列表
GET    /api/folders/{id}/children?…（同上分页/排序参数）                   子文件夹 + 媒体项混合分页
GET    /api/search?q=xxx&page=1&size=20&sort=relevance|mtime              模糊搜索（默认相关度）
GET    /api/media/{id}                           元数据（时长/编码/同文件夹上下个）
GET    /api/media/{id}/stream                    视频流（支持 Range → 206；?transcode=1 走 HLS）
GET    /api/media/{id}/image?w=400               封面/图片（服务端缩放）
GET    /api/media/{id}/subtitles                 外挂字幕(M2) / 内嵌提取(M3)
POST   /api/progress                             断点上报（M1 本地存储 / M3 多设备同步）
```

**分页默认 size=20，与需求"每页 20 个"一致。**

### 13.1 实施偏差说明（与需求的差异，均为简化取舍）

1. **FR-1.6 配置文件为 `config.json` 而非 config.yaml**——零第三方依赖即可读写，管理页可视化配置不受影响。
2. **FR-4.8 ass 字幕由服务端转换为 VTT**（提取文本轨，不保留特效样式）而非前端 libass 渲染——省去 2MB+ wasm 依赖；srt 完整支持。
3. **FR-4.11 内嵌 PGS 图形字幕轨不支持**（返回 415 提示），文本轨（srt/ass/mov_text）支持提取。
4. **FR-1.9 托盘与开机自启仅 Windows**；macOS/Linux 保持控制台运行（跨平台托盘需 CGO，留待 M4 Tauri 方案）。
5. 中文排序为 Unicode 码点序（拼音序由搜索的拼音匹配部分补偿）。
6. 库根目录直接放置的文件只参与搜索、不进浏览列表（需求假设母文件夹/子文件夹结构）。

## 14. 附录：浏览器编码兼容速查（实施依据）

| 容器/编码 | iOS Safari | Android Chrome | 桌面 Chrome/Edge | 桌面 Firefox |
|---|---|---|---|---|

| WebM/VP9 | ✅ | ✅ | ✅ | ✅ |
